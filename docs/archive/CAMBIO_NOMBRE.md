## 🚀 Impacto en Vercel

### URL del proyecto en Vercel:
Cuando despliegues en Vercel, la URL por defecto será algo como:

```
https://icfes-colegio-[hash].vercel.app
```

O si ya desplegaste con el nombre anterior, puedes:

1. **Opción A: Mantener el deployment actual**
   - El nombre interno puede ser diferente de la URL
   - No afecta el funcionamiento

2. **Opción B: Crear nuevo proyecto en Vercel**
   - Elimina el proyecto anterior
   - Importa de nuevo con el nuevo nombre
   - La URL reflejará "icfes-colegio"

3. **Opción C: Renombrar en Vercel**
   - Ve a Vercel Dashboard
   - Settings → General
   - Cambiar el nombre del proyecto
