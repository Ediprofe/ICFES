7. Clasificación de plantel

Compara la clasificación del plantel entre grupos de cohortes basada en el índice global

📖 Metodología de cálculo

1. Muestra base (sin PIAR)

Se excluyen estudiantes con PIAR de cada cohorte para obtener la muestra base.

2. Top 80% por área

De la muestra sin PIAR, se selecciona el 80% de mejores puntajes en cada área académica independientemente.

3. Índice de área

Fórmula: Índice = Promedio / (1 - Varianza)

  • Tabla de frecuencias: Se crea para puntajes 0-100 (101 filas)
  • FRA (Frecuencia Relativa Acumulada): Se calcula de mayor a menor (desde 100 hasta 0). FRA[i] = proporción de estudiantes con puntaje ≥ i, donde i es cada puntaje de 0 a 100
  • Promedio: Σ(FRA de todos los puntajes 0-100) / 101
  • Varianza: Σ((FRA - Promedio)²) / 101
  • El índice resultante está en escala 0-1

4. Índice global

Fórmula:

IG = [(3 × MA) + (3 × LC) + (3 × CN) + (3 × SC) + IN] / 13

MA: Matemáticas | LC: Lectura Crítica | CN: Ciencias Naturales | SC: Sociales | IN: Inglés
